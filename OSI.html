💡 考前必記： IPAS 題目常考「哪種攻擊發生在 OSI 哪一層」或是「WAF 與 IPS 的差異」。記住：只要看到 HTTP/DNS/SQLi，一律先想第七層！
TCP/IP 4層 OSI 7層模型 對應服務 / 協定 代表設備 常見攻擊 防禦手段
應用層
(Application)		 L7 應用層 HTTP, HTTPS, DNS, FTP, SMTP, DHCP, Kerberos L7 Switch, WAF, 閘道器 SQLi, XSS, 憑證填充, DNS 污染 WAF, 2FA/MFA, 輸入驗證
L6 表現層 SSL, TLS, ASCII, JPEG, 加密/解密 (通常為軟體實作) 加密演算法漏洞 (如 Heartbleed) 更新加密套件, SSL Inspection
L5 會議層 RPC, NetBIOS, SQL Session (主機作業系統) 會話劫持 (Session Hijacking) Session Timeout, Token 隨機化
傳輸層
(Transport)		 L4 傳輸層 TCP, UDP L4 Switch, 狀態檢查防火牆 SYN Flood, Port Scan 流量清洗, 防火牆 ACL, IDS/IPS
網際網路層
(Internet)		 L3 網路層 IP, ICMP, ARP (有爭議), IPsec 路由器 (Router), L3 Switch IP Spoofing, ICMP Flood (Smurf) IPsec VPN, 路由器過濾
網路存取層
(Network Access)		 L2 資料連結層 Ethernet, MAC, PPP, ARP 交換器 (Switch), 網橋 ARP Spoofing, MAC Flooding Port Security, DAI (動態 ARP 檢測)
L1 實體層 Bits, 電壓, 介面規格 (RJ45) 集線器 (Hub), 中繼器, 線材 實體破壞, 訊號側錄 (Sniffing) 實體門禁, 屏蔽線材
📝 技術考點補強：
  • WAF： 運作在 L7，專門處理 HTTP/HTTPS 的負載內容。
  • IPsec： 運作在 L3，分為傳輸模式與穿透模式（Tunnel Mode）。
  • Kerberos： L7 的認證協定，關鍵物件為 TGT 與 Service Ticket。
  • SUID： Linux 權限值為 4000，可用於本地提權攻擊（如 Dirty COW）。
